How the academic frontend demonstrates customer-data handling.

Information Collection

SmileHub may collect account, address, cart, and order details required to demonstrate an e-commerce transaction.

Use of Information

Information is used only to show customer profiles, checkout, order history, and notifications in this frontend project.

Browser Storage

Cart, wishlist, theme, and demo orders are stored in your browser using localStorage. No data is sent to a server in this version.

Security
