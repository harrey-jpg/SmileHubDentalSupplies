Read Terms
🎓Academic demonstration. SmileHub is a frontend class project, not a live store. No real transactions occur and no personal data is sent to a SmileHub server in this version.

Information Collection

SmileHub collects only the details needed to demonstrate an e-commerce transaction: account names and email addresses, delivery addresses, cart contents, and order records you create while exploring the demo.

We never ask for real payment credentials, government IDs, or health records. Any checkout information you enter — including GCash numbers or card details — is treated as sample input and never transmitted or charged.

Use of Information

Information is used solely inside this frontend project to render customer profiles, drive the checkout flow, display order history, and trigger on-screen notifications.

  • Show your profile, wishlist, and cart across pages.
  • Simulate checkout totals, shipping estimates, and order confirmations.
  • Personalize demo content such as recently viewed products.

Browser Storage

Cart, wishlist, theme preference, and demo orders are stored in your own browser using localStorage. No data is sent to a SmileHub server in this version.

Clearing your browser's site data removes everything the demo saved. If you use Firebase login, authentication tokens are managed by Google Firebase under its own policies (see Data Processors).

Data Processors

This academic project uses Google Firebase for authentication and cloud storage. When you sign in with Firebase, Google processes your credentials under the Google Privacy Policy. All other data handling in the demo is simulated locally in your browser.

Security

Because this is a frontend demonstration, protections are limited to browser-level storage and Firebase's built-in authentication safeguards. The planned backend phase will add server-side authentication, input validation, secure password hashing, database access controls, and role-based permissions before any real customer data is handled.

Contact Us

Questions about this policy or requests to review, correct, or delete demo data? Reach us through the Contact Us page. Support for this academic project is based in Quezon City, Metro Manila.
